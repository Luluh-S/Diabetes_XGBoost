# Find the 30

Our presentation for the diabetes mini project (CDC BRFSS 2021, XGBoost and Gradient Boosting). 14 slides.

## How to open it

Download `presentation.html` and open it in Chrome, Safari or Edge. It needs an internet connection for the fonts.

- Right arrow, space or click: next slide
- Left arrow: previous slide
- F: full screen
- N: show the speaker notes

## What is inside

- `presentation.html`: the whole deck in one file
- `source/`: the slide files it was built from (`deck.json` has the slide order)
